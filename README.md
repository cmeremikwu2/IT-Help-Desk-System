# IT Help Desk Ticket Management System

## Project Overview

The IT Help Desk Ticket Management System is a web-based application designed to help users submit and manage IT support requests.

## Current Features

- Submit IT support tickets
- Enter the user's name
- Enter the problem and description
- Set ticket priority
- Generate ticket numbers
- Track ticket status
- Change tickets from Open to In Progress
- Mark tickets as Resolved

## Technologies

- HTML
- CSS
- JavaScript

## Current Progress

The current version is a functional prototype. Future development will include database integration, user authentication, ticket history, and additional ticket management features.
